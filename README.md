# PROJECT Q: 질문이 사라진 도시

AI 윤리 문제를 탐색하고 학생이 직접 질문을 만들어 해결하는 N-ASKIN 기반 2D RPG 웹게임입니다.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 만듭니다.
2. 이 압축파일을 풀고 `index.html`, `game.js`, `styles.css`, `assets`, `gas` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 `Settings > Pages`로 이동합니다.
4. `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 저장합니다.
6. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

`index.html`이 저장소 최상위에 있어야 정상적으로 실행됩니다.

## 조작 방법

- 키보드: 방향키 또는 WASD 이동, E·Space 조사
- 태블릿: 화면 터치 이동, 이동 버튼, Q 조사 버튼
- 진행 기록은 브라우저에 자동 저장됩니다.

## 교사별 Google 스프레드시트 연결

1. 새 Google 스프레드시트에서 `확장 프로그램 > Apps Script`를 엽니다.
2. `gas/Code.gs` 내용을 붙여넣고 저장합니다.
3. 스프레드시트를 다시 열고 `PROJECT Q > 기록 시트 준비`를 실행합니다.
4. Apps Script에서 `배포 > 새 배포 > 웹 앱`을 선택합니다.
5. 실행 사용자는 `나`, 접근 권한은 수업 환경에 맞게 설정합니다.
6. 발급된 `/exec` 주소를 게임의 `교사 연결 설정`에 입력합니다.

학생은 스프레드시트 편집 권한 없이 게임에서 기록을 제출할 수 있습니다.
